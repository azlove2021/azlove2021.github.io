设计思路

Harness 让 Agent 在真实场景中持续工作

◈

Cordis 内核

只负责插件的加载、卸载和依赖关系，不承载 Agent 的具体能力。

▦

插件提供能力

模型、工具、技能、存储……所有能力均由插件提供，通过服务与事件彼此协作。

⚙

配置层自由组合

无需改动源码，即可在配置层选择、替换或扩展任一能力。

多种运行模式

同一模型，放进不同环境，做事方式不一样

推荐

标准模式

功能完整的编码 Agent：文件编辑、Shell、文件与网页检索、Skills、计划、目标、子代理和工作流。

PTC 模式

具备标准模式全部能力，通过 Code Mode SDK 呈现工具，让模型用一个 TypeScript 程序组合多步操作。

极简模式

仅提供持久 bash 与文件编辑器两种工具的极简 Agent，用于最小化环境下的模型基准测试。

创造模式

用于创建自定义 Agent preset：提供运行时检查、插件实验和 preset 创作指导，亲手拼出你的智能体。

每一次运行，都有迹可循

对话是「说了什么」，轨迹是「到底怎么干的」。每一步请求、每个工具调用、每次 token 消耗，全部可见。
