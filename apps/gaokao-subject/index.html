家长必读 贵州新高考 3+1+2 模式

贵州新高考选科指南（家长版）

一文读懂「3+1+2」选科、赋分制的利与弊，以及女生、理科偏弱、二本边缘孩子的最优组合。

1贵州新高考：3+1+2 怎么考？

贵州从 2021 年秋季入学的 高一新生 起，实行新高考改革。考试不再分文理，而是「3+1+2」模式，总分 750 分。

「3」全国统一科目：语文、数学、外语。每科 150 分，卷面原始分计入总分。
「1」首选科目：物理 / 历史，二选一，100 分，原始分计入。
「2」再选科目：化学、生物、政治、地理，四选二，每科 100 分，等级赋分计入。
总分语文 + 数学 + 外语 + 物理/历史 + 2 门赋分 = 750 分。

选科决定高考报考专业范围。不同组合可填的专业覆盖率差距巨大：

首选再选组合（例）可报专业覆盖率
物理化学+生物≈ 95% 以上（理工医基本全开）
物理化学+政治≈ 90%（理工医 + 公安）
物理地理+政治≈ 50%（限理工文兼收）
历史政治+地理≈ 50%（人文社科为主）
历史化学+生物≈ 40%（文科 + 少部分医学）
⚠️ 重要提醒：很多专业有「选科要求」硬门槛。比如临床医学类多数要求「物理+化学」双选；公安学类大多要求「政治」。选科前一定要看贵州省发布的《普通高校招生选考科目要求》。

2赋分制是什么？怎么算？

「再选科目」因为不同学科难度不同、报考人数不同，原始分没法直接比较。所以新高考引入「等级赋分」，把同一选科群体里所有人的原始分按比例重新映射到 100～40 分的区间，再计入高考总分。

① 21 个等级划分

把所有考生按卷面分从高到低排序，划成 21 个档位（A、B、C、D、E 五档，每档再分 5 小档），比例如下：

③ 原始分 → 赋分换算公式

赋分 = ( Ymax − X ) ÷ ( Ymax − Ymin ) × ( Tmax − Tmin ) + Tmin
X = 原始分　Y = 同档内原始分最低/最高　T = 同档赋分最低/最高

举个例子：

孩子化学考了 65 分（原始分），排名在 B3 档（占同科前 9%）。

B3 档赋分区间是 76～71 分。再根据同档内 Ymax 和 Ymin 算下来，最终赋分约 73 分 左右。

3赋分的优势

  • 弥补学科难度差异。物理、化学卷面分天然比政治、地理难，赋分后大家站在同一把尺子上，对偏文科孩子友好。
  • 弱化「绝对分」博弈。只要相对排名稳定，赋分就稳定。不用跟全省学霸拼原始分。
  • 鼓励按兴趣选科。难度系数被赋分抵消，家长和孩子可以更放心地根据兴趣、规划来选，不用死磕最难的科目。
  • 放大「中分段」优势。原本中等生选化学赋分能到 70+，比选物理拿 50 分划算很多。这就是「选对赛道」的红利。
  • 避免「弃考」陷阱。以前文理分科，差生直接放弃理化；赋分后认真考也能拿到相对可观的分数，提升总成绩。

4赋分的劣势

  • 顶尖生赋分可能「缩水」。物理原始分 95 分，全省前 1%，赋分依然是 100，看起来没亏；但化学原始分 90 分，赋分可能只有 88～90，好成绩被抹平。
  • 赛道选择影响赋分。某科目选的人少、你排名靠前，赋分天然高。选的人扎堆学霸，你的赋分就被压低。这叫「博弈型选科」，对中等生有风险。
  • 原始分 1 分可能 = 赋分 3 分。一分一段表不再是线性的，家长看成绩单容易误判，容易「看赋分以为考砸了，看原始分才安心」。
  • 复读成本变高。赋分依赖当年同科考生分布，每届不一样，复读一年的「同科对比」失效。
  • 同班同学赋分差异大。同样化学卷面 80 分，你 B 档赋 75，他可能 C 档赋 65，容易引发「不公平感」。

🔍 给家长最直白的翻译：

赋分 = 把你的分数按全年级排名重新定价。

好处是「中等偏上选对科目能弯道超车」；坏处是「学霸高分被稀释、卡在中段的人波动大」。

5女生理科偏弱、二本边缘：怎么选？

基本情况：女生 · 理科薄弱 · 总分在二本线附近。目标是「尽量上个好大学 + 方便考公考编 + 好就业」。

核心策略：首选「历史」（避开物理），再选组合里把政治放第一，生物或地理放第二。这是二本边缘女生在过去几年新高考里最稳、最容易考上公办本科、最方便考公考编的一条路。

① 推荐组合：历史 + 政治 + 生物（最推荐）

历史 政治 生物

✅ 优势：

• 三个科目整体背诵 > 计算，理科薄弱孩子完全跟得上。

• 政治覆盖公务员 80% 以上岗位招录门槛，是考公第一科目。

• 生物赋分通常比物理化学划算：理科生集中选物理化学，生物赛道相对宽松，中等分能换高赋分。

• 可报专业约 45%：汉语言文学、法学、会计、审计、税务、新闻、护理、师范、医学检验、中医、部分管理类。

• 适合未来方向：法学 → 公务员、师范 → 教师编、财会 → 国企会计、医学相关 → 医院/疾控。

② 备选组合：历史 + 政治 + 地理（传统文科）

历史 政治 地理

⚠️ 注意：

• 最纯文科组合，学霸扎堆，赋分竞争最激烈（"文科卷"不是段子）。

• 地理看似简单，但是文科里最难的学科（自然地理需要理解）。

• 二本边缘孩子如果选这个组合，赋分上容易被甩开。

• 除非孩子地理确实强、对政治兴趣一般，否则不优先推荐。

③ 谨慎选择：历史 + 化学 + 生物 / 历史 + 化学 + 地理

❌ 不建议：

• 化学对理科薄弱孩子是硬骨头，赋分赛道里学霸密集，中等分容易被甩。

• 二本边缘选化学，不是勇敢而是冒险。

• 除非孩子化学高一就在 70 分以上、且化学老师评价好，可以考虑。

6女生考公考编，哪些专业对口？

新高考选科后，专业选择直接决定未来考公考编能报的岗位数。以下是「历史 + 政治 + 生物」组合下，最值得考虑的本科专业（考公考编方向）：

法学公务员岗位最多的万金油专业，纪委、政法委、法院、检察院、司法局都招。
汉语言文学考公务员、事业编"铁饭碗"专业，招录面最广，竞争小。
会计学/审计税务局、财政局、审计局、银行、国企每年都招，岗位稳定。
财务管理和会计接近，岗位同样多，且企业就业也稳。
学前教育考公办幼儿园编制容易，工作相对轻松但收入一般。
小学教育公办小学教师编，师范类专业竞争激烈但岗位多。
新闻学宣传部、融媒体中心、文广局等事业编岗位。
护理学医院编制多，但工作强度大。需确认有无选科限制（部分要求化学）。
中医学部分省份招中医编，但部分中医院校要求「物理+化学」，务必查贵州的招生要求。

💡 选科之后的目标分解

  • 高考目标：努力冲到二本线 30 分以上，进入公办本科（学费低、师资好、考公考编有优势）。
  • 大学目标：大一就开始准备考公，入党 + 拿奖学金 + 学生干部经历。
  • 专业目标：法学、汉语言文学、会计是考公三大"亲妈专业"。
  • 就业兜底：教师资格证、会计初级职称、普通话证——大学期间全拿下。

7给家长的 3 句实在话

① 别等高三再想选科，高一就要开始规划。

新高考「3+1+2」一旦选定，就跟到高考。中间改选代价大，最迟高一结束必须确定。

② 选科看「分数」更看「赋分」。

不要被单次月考原始分吓到，看孩子在全年级、全市的赋分档位，低分高赋才是真本事。

③ 考公考编是「长线投资」。

从选科 → 选专业 → 大学入党 → 大四考公/考编，每一步都连贯。理科薄弱的孩子选「历史+政治+生物」，这是性价比最高的起点。
